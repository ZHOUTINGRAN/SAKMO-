项目已按内容分类创建好文件夹。将你的图片文件（.jpg / .png / .webp 等）直接放入对应文件夹即可。

💡 快速操作

1. Windows：直接在资源管理器中复制粘贴图片到对应文件夹
2. 批量替换：上传后用搜索替换功能批量更新 HTML 中的路径
3. 压缩建议：单张图片 ≤ 500KB，支持 JPG / WebP 格式
4. Git 提交：图片文件会自动被 Git 跟踪，提交即可同步到 GitHub
