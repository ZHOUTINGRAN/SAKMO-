长线企划 / Project 03

城市边缘发展City's Edge

吊车、围挡、塔吊与野草——城市向外蔓延的临界线。这里既不是城，也不是乡，而是一种永远在"即将成为"的状态。两位摄影师，一拍硬的、一拍软的。

摄影师陆深 · 周野启程2026 春状态进行中
DEEP READ / 深度解读

城市边缘是一种"中间地带"：规划图上已经画好了红线，地图上却还来不及更新。这里塔吊林立、围挡连绵，野草从水泥缝里钻出来，与未干的混凝土争夺同一块地。我们感兴趣的不是"建好了什么"，而是"正在建成什么"——这种悬而未决的状态，比任何完工的楼盘都更诚实。

拍摄多在黄昏进行。这个时候，塔吊的剪影像巨大的骨架立在天际线上，工地的探照灯刚刚亮起，而远处的乡村还残留着白昼的余温。光的过渡，恰好对应着这片土地身份的过渡。

陆深拍"硬"的部分——钢结构、围挡板、未完工的混凝土立面；周野拍"软"的部分——围挡边生长的野草、临时工棚里晾的衣服、工人在脚手架下抽烟的影子。两种质地并置，构成一份关于城市扩张临界线的视觉档案。
