纯原生 Header 组件

这是完全基于原生 HTML / CSS / JavaScript 实现的 Header 组件，没有任何外部依赖（不需要 jQuery、TweenLite 或任何框架）。

包含的交互效果：

• 汉堡 ↔ 关闭图标切换（CSS transform 旋转 ±15°）

• 菜单抽屉从右侧滑入（cubic-bezier 缓动曲线）

• 菜单项 hover 黑块覆盖动画（CSS transition）

• 页面滚动时 Header / Logo / 按钮同步缩小并上移（.is-scrolled 类）

• mix-blend-mode: difference — 在图片背景上自动反色

• 支持 ESC 键关闭菜单

滚动测试区

继续向下滚动，观察 Header 在上滑过程中的缩小动画。再次滚回顶部，Header 会恢复原始大小。

点击右上角的汉堡按钮打开抽屉式导航菜单，菜单中的 hover 动画同样用纯 CSS transition 实现。

所有动画都使用 cubic-bezier(0.2, 0.7, 0.2, 1) 缓动曲线，视觉手感与原始项目保持一致。

在手机屏幕（宽度 < 768px）上，hover 动画会被禁用，避免触摸设备上的误操作。

Header 使用 mix-blend-mode: difference 属性，这意味着在深色/彩色背景上 Logo 和汉堡按钮会自动反色，在白底上则显示白色——无需额外判断背景颜色。
