Open Call · 客座投稿

每期随机主题开放客座投稿，常驻与客座同台陈列。无论你拍的是乡镇、田野、城市边缘，还是窗台上一只打盹的猫——只要目光诚实，都欢迎把作品寄给我们。

投稿规范Submission Specs

Last Updated · 2026.08
主题 / Theme
当期征稿主题「树」窗里与窗外、光的入口与视线的出口——可纪实、可静物、可创意，鼓励与节气气息呼应。
格式 / Format
单张或组图（4–12 张为一组）推荐 WebP / AVIF；JPG、PNG、TIFF 亦可。
尺寸 / Size
长边 ≥ 3000px，色彩 sRGB单张文件不超过 25MB；组图请打包为 zip。
文件 / File
请保留 EXIF投稿者须为原著作权人或已获合法授权；作品需附署名、拍摄时间与一句话手记。
截稿 / Deadline
2026 · 9 月 20 日 24:00 (UTC+8)逾期稿件将顺延至下期评估，不另行通知。
投稿方式 / Submit
邮件至 sakmo@jasakura.cn主题注明「投稿 · 客座 · 你的署名」；正文附社交账号与作品手记，附件或网盘链接均可。
